# RTCRangeHelper

An application for help find the error RTC range to fix the RTC/CMOS memory error when the hackintosh wake from sleep or every time that boots.

## Features

- Guide where you need to add the `rtcfx_exclude` and `rtc-blacklist`
- Support multiple ranges
- Able to restart the process if you want
- Identifies if it's not a RTC problem
- Show the current range excluded every time that start the program

## How to use

1. Download the source code
2. Install [Python 3.12.14](https://www.python.org/downloads/release/python-31214/)
3. Run the `RTCRangeHelper.py` with `python3 RTCRangeHelper.py` command
4. Follow the instructions in the program
